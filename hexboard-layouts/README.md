# Hexboard layouts

These are ordinary FUTO Keyboard layouts. Nothing in them is specific to hexagons.

Hexagonal keys are a display setting (Theme screen > "Hexagonal keys"). When it is on, the keyboard
re-flows whatever layout is active onto a hexagonal grid: every key is snapped to a whole number of
grid cells and every row is shifted half a cell from its neighbours. Any number of keys per row
works, including layouts written in the in-app YAML editor.
